# Atalaya Studio

Sitio web de **Atalaya Studio**, el proyecto que sirve de caso práctico en la materia Desarrollo Web de la especialización en la Corporación Universitaria de Asturias. El proyecto crece unidad tras unidad:

- **Unidad 1:** landing page con HTML5 semántico, CSS responsive, JavaScript en módulos y testimonios cargados desde una API.
- **Unidad 2:** API propia con Node.js y Express para el formulario de contacto, preferencias guardadas en `localStorage` (modo oscuro, nombre, últimos servicios vistos), microinteracciones y despliegue (frontend en Netlify o Vercel, backend en Render).
- **Unidad 3:** control de versiones, mantenimiento, pruebas y documentación.
